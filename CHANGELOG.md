# Changelog

## 2.3.2 (30 September 2026)

- Shortened settings, toolbar, help and store text.
- Corrected the postage-threshold description.
- Renamed the selection button setting to cover marked and unmarked orders.

## 2.3.1 (30 September 2026)

- Bulk selection skips disabled eBay checkboxes and excludes them from the button count.
- Turn inversion off to edit selection rules. Your previous choices remain saved.
- Added automated checks for dispatch page settings, normal and inverted bulk selection, disabled checkboxes, settings controls and navigation between order pages without reloading.
- Chrome packaging runs regression checks before building the ZIP.

## 2.3.0 (30 September 2026)

- Added overdue, due within 24 hours and express delivery subpages to the Awaiting dispatch setting.
- Added inverted selection to select orders with no highlights on the current page.
- The bulk button displays Select unmarked or Clear unmarked while inversion is on.

## 2.2.0

- Added a separate Special Delivery mark.
- Reads other pages of the current order list for counts and same-buyer matching.
- Shows a notice when highlighted orders are on another page.
- Added an option to hide zero counts and singular/plural count text.

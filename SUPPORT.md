# Order Marks support

Before reporting a problem:

1. Confirm you are using an eBay UK Seller Hub order page.
2. Reload the order page and turn on Order Marks.
3. Open Order Marks settings and enable the current order-page type.
4. Compare your thresholds with the order totals and postage charges.
5. For overdue, due within 24 hours or express delivery orders, enable **Awaiting dispatch** in settings.
6. If bulk selection picks unmarked orders, check **Invert selection: select unmarked orders** under **Toolbar and selection**. Turn it off to select marked orders using your chosen rules.
7. You cannot select disabled eBay checkboxes. They do not count toward the selection total. Turn inversion off to edit individual selection rules.

If the problem continues, [open a GitHub issue](https://github.com/evenwebb/order-marks-downloads/issues/new). Include the extension version, browser version, affected Seller Hub page, and a short description of what happened.

Do not include customer names, addresses, buyer IDs, order numbers, tracking numbers, or other private order information.

# Order Marks support

Before reporting a problem:

1. Confirm you are using an eBay UK Seller Hub order page.
2. Reload the order page and check that Order Marks is enabled.
3. Open Order Marks settings and confirm the current order-page type is enabled.
4. Check that your rule thresholds match the orders you expect to be marked.

If the problem continues, [open a GitHub issue](https://github.com/evenwebb/order-marks-downloads/issues/new). Include the extension version, browser version, affected Seller Hub page, and a short description of what happened.

Never include customer names, addresses, buyer IDs, order numbers, tracking numbers, or other private order information.
